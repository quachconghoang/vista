# Python ideation

Read `AGENTS.md` first. Use this skill for exploratory algorithms, experiments, data preparation, and reference implementations.

## Workflow

1. Inspect related code and tests before editing.
2. State assumptions and keep the prototype readable.
3. Use type hints and deterministic inputs where practical.
4. Add focused tests or a reproducible experiment for the behavior.
5. Run the narrowest relevant Python checks.
6. Clearly record limitations and what should be optimized later in C++.

Do not prematurely optimize the prototype or introduce unnecessary dependencies.
